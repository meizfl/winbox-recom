Baseline native WinBox Recom packages for Linux x86-64 and Intel Macs, built through static recompilation with a custom compatibility runtime. Wine and Proton are not required.

### Packages

- `winbox3-linux-amd64`: fully static ELF targeting Debian 11+, with X11 and native Wayland support.
- `winbox3-macos-x86_64.zip`: Intel Mac application targeting macOS 10.14+, with statically linked third-party libraries and Apple system frameworks.

On Linux, run `chmod +x winbox3-linux-amd64` and launch the executable. On macOS, extract the ZIP and open `WinBox Recom.app`.

### Validation

This release passed the baseline runtime tests, native headless Wayland presentation and Debian 11 startup checks. The packaged Mac app passed a Cocoa startup check. Architecture, macOS deployment target and the absence of third-party dynamic-library dependencies are verified automatically.

The Mac package is ad-hoc signed and not notarized by Apple. Physical macOS 10.14 validation remains outstanding. Checksums are included in `SHA256SUMS`; router profiles and credentials are not included.

This is a preview of an experimental compatibility runtime. Later releases add themes, vector icons, wallpapers, Apple Silicon packages and native HiDPI rendering.
